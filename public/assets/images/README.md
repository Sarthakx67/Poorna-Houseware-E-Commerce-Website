# Images for final-2

Place all product/category images used by the app in this folder.

How paths work in this project:
- The code references images with absolute paths like `/assets/images/xxx.jpg`.
- In Vite, any files under `public/` are served at the site root.
- Therefore, files placed here are reachable at `https://<host>/assets/images/xxx.jpg` in dev and production.
